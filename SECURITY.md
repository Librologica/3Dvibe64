# Security policy

3Dvibe64 1.12.0: [EN optimization contract](RENDER-OPTIMIZATIONS.en.md) · [Contratto IT](RENDER-OPTIMIZATIONS.it.md).
All examples require external inputs / Tutti gli esempi richiedono input esterni.


## Supported version

Security fixes are applied to the latest published 1.x release of 3Dvibe64.
Older snapshots and modified forks are not maintained by librologica.digital.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion or pull
request. After the repository is published, use GitHub's private vulnerability
reporting or a private repository security advisory. The repository owner must
enable private vulnerability reporting in **Settings → Security → Code security
and analysis**.

Include the affected version, a minimal reproduction, the impact, prerequisites
and any suggested mitigation. Remove secrets, personal data and unrelated
third-party material from the report.

librologica.digital will assess reports and coordinate disclosure when a fix is
available. No response-time or bounty commitment is made by this document.

## Italiano — politica di sicurezza

### Versione supportata

Le correzioni di sicurezza si applicano all'ultima release 1.x pubblicata di
3Dvibe64. Snapshot precedenti e fork modificati non sono mantenuti da
librologica.digital.

### Segnalare una vulnerabilità

Non divulgare una vulnerabilità sospetta in un'issue, discussione o pull request
pubblica. Dopo la pubblicazione del repository, usare la segnalazione privata
delle vulnerabilità di GitHub o un advisory privato di sicurezza del repository.
Il proprietario deve abilitare tale funzione in **Settings → Security → Code
security and analysis**.

Includere versione interessata, riproduzione minima, impatto, prerequisiti ed
eventuale mitigazione suggerita. Rimuovere segreti, dati personali e materiale
di terzi non pertinente dalla segnalazione.

librologica.digital valuterà le segnalazioni e coordinerà la divulgazione quando
sarà disponibile una correzione. Questo documento non promette tempi di
risposta o ricompense.
