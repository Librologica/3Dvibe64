# Native qualification — 1.15.1

This stable promotion cold-rebuilds the full fixed benchmark catalog from
the delivered agentic17 renderer/public API bytes, with stable VERSION1.15.1.
All54 buildable PRGs and every numeric label match;162 saved native observations
at1×/20×/64× are retained by exact identity.27 existing build failures remain;
no additional combination is silently removed. This is not a new timing run.

The qualification build snapshot froze renderer/API/VERSION while release docs
and host gates were still being updated. Final delivery separately proves those
renderer/API/version inputs identical. [Machine-readable qualification](QUALIFICATION-1.15.1.json)
contains all native metrics, program/command hashes, supported scope and flags.
