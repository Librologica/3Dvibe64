# 3Dvibe64 1.20.1

Stable source SDK. Modes 1 and 2 reduce work in shallow wire spans, material caching and near-plane projection. Mode 8 speeds up ray traversal and inner rendering routines in its mono and multilayer backends.
SDK sorgente stabile. Le Mode 1 e 2 riducono il lavoro negli span wire poco inclinati, nella cache dei materiali e nella proiezione vicino al piano di clipping. La Mode 8 accelera la percorrenza dei raggi e le routine interne dei backend monolivello e multilivello.
