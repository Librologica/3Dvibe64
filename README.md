GraphicsMode 1–8 remain available with explicit external scene inputs. Legacy
precision remains the ordinary default; Q8 and optimizations are opt-in.
Ordinary options include meshSourceSharing, FaceCullProfile, Mode4NearProfile
and HeaderText; text split uses 160×88, TEXT_HEADER_SCREEN_BYTES.
See [Mode6 report](GOURAUD-MODE6-REPORT.md) for the historical raster contract.
Native engine templates are backend implementations, not bundled demo projects;
Mode8 retains its bounded topology and requires the caller's map input.
