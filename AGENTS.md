# 3Dvibe64 1.20.0 source SDK

This is the published stable source release 1.20.0, promoted from agentic36. Release: https://github.com/Librologica/3Dvibe64/releases/tag/v1.20.0. Preserve this official source snapshot and all historical tags/releases. New engine work belongs in a separate development directory.

Engine code, defaults and bounded API contracts are unchanged from agentic36. Work in a separate directory. Keep demos, application assets and benchmark suites outside the source package. Correctness tests are included; see TESTING.md. Do not spawn subagents for this SDK unless the user explicitly requests them.

After rendering changes, measure actual new complete views on the native target after warm-up for at least 20 emulated seconds, preserving raw data, commands, PRG and matching symbols, mean FPS and available p95/worst intervals. CPU replay and host/warp time are not native FPS. Documentation or packaging changes can inherit native measurements only with unchanged runtime and exact measured PRG/all-numeric-label identities and conditions. Report inherited measurements as inherited, not new runs.

Keep the historical general index anchored at 1.15.0=100. Include base/new values and percent change in optimization reports and label reconstructed estimates. The independent extended index stays anchored at first-delivered agentic36=100. Do not change weights, workloads or blocked-case policies to improve a score.
