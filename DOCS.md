## Scope / Perimetro

Complete API and scene-format examples are documentation fragments, not bundled applications. Correctness tests are included; demos and performance suites are external. Experimental/bounded profiles retain the limits in their contracts. Native claims apply only to recorded target configurations.

Gli esempi di API e formato scena sono frammenti documentali, non applicazioni incluse. Sono presenti test di correttezza; demo e suite prestazionali sono esterne. I profili sperimentali/delimitati conservano i propri limiti. Le misure native valgono per le configurazioni registrate.
