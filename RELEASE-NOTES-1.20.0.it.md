# Note di release — 1.20.0

Release stabile dalla agentic36, pubblicata su GitHub. Distribuzione di soli sorgenti: nessuna demo, benchmark, PRG, musica o asset applicativo incluso.

La promozione conserva l’engine qualificato: ottimizzazioni esatte ereditate nelle otto modalità, AnimatedMesh nativa, RuntimeScene, cache opzionali e API applicative delimitate. Distance Fade è disponibile nelle modalità 1–8 e resta disattivato per default; il LOD texture Mode7 resta indipendente. Conservati i 17 livelli Bayer e l’aritmetica Q8. Sono incluse cache dei livelli per piano e riempimenti Bayer a passo quattro Mode8 multi, calcolo esatto della distanza poligonale e correzione delle scritture dei proprietari wire della agentic36.

Documentazione IT/EN aggiornata per API, limiti, compilazione con input esterni, memoria, test e tipi di scena in cui il fade conviene o costa più del lavoro risparmiato. I rapporti numerati precedenti restano storici.
