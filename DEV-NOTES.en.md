# Technical notes — 1.15.0

Stable source package prepared locally and not published. Promotion from1.15.0-dev2 changes documentation, version, metadata and distribution checks; all implementation bytes under work/ and all executable/configuration modules under extensions/ remain unchanged.

Includes exact arithmetic, edge recurrences, block spans, outcodes, conservative panel adapters, wire/stream APIs and a lossless keyframe codec. Defaults `legacy` and `-LegacyPlusOptimizations none` remain unchanged. New kernels/APIs are qualified only within the documented Mode4 legacy-plus profile; ordinary Mode1–7 plus support is separate. Gameplay and Normalized16 retain their experimental status: a stable package version does not broaden their qualification.
